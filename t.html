Introducción

El objetivo de este trabajo es analizar los datos disponibles en el Banco Mundial sobre las tasas de pobreza a nivel mundial y examinar las diferencias, si las hubiera, entre la tasa de pobreza a nivel nacional y la tasa de pobreza a nivel internacional.

Para ello, en este trabajo hemos decidido utilizar estas dos variables: la tasa de pobreza a nivel nacional (SI.POV.NAHC) y la tasa de pobreza a nivel internacional (SI.POV.DDAY). Además, hemos utilizado los datos del PIB per cápita (NY.GDP.PCAP.CD) y la variable de población (SP.POP.TOTL).

Nuestra hipótesis principal es que los países con el PIB más alto son aquellos con el menor porcentaje de población pobre.

No nos hemos centrado en ninguna zona específica, por lo que el marco geográfico que utilizamos es el mapa mundial completo. En cuanto al contexto temporal, hemos trabajado con todo el período de datos ofrecido por el Banco Mundial, es decir, desde 1980 hasta 2024, si bien nuestra intención ha sido utilizar los datos más recientes posibles para todos los países.

Manipulación de los datos

Para centrarnos mejor en nuestro tema principal, filtramos los datos de las dos variables relacionadas con la pobreza para conservar el último año con información disponible para ambas variables en la base de datos del Banco Mundial, eliminando así los datos faltantes de estas variables en nuestra investigación. A lo largo del trabajo, creamos tablas para comprender mejor los datos, ordenando los países según el mayor porcentaje de población por debajo del umbral de pobreza, tanto con las variables nacionales como internacionales, y con ambas simultáneamente; ordenándolos por áreas geográficas y observando cuál ofrece la mayor cantidad de datos para cada una, restando los datos obtenidos por la variable nacional de los obtenidos por la variable internacional, para así comprobar si existe una diferencia significativa. También creamos tablas donde aparece la variable PIB per cápita, para contrastar nuestra hipótesis.

Para que el trabajo fuera más visual y los datos más fáciles de entender, creamos un mapa que muestra los porcentajes de población pobre en cada país mediante una escala de color del amarillo al morado. Existen varios mapas: uno para la variable a nivel nacional, otro para el nivel internacional y un tercero para la diferencia entre ambas variables.
